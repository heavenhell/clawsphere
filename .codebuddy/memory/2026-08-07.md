# 2026-08-07

## 代码检视 — 为各模块建立 __init__.py 索引

为 clawsphere 项目的所有 Python 模块补充了 `__init__.py` 索引文件，支持简洁导入。

### 修改的文件

| 模块 | 导出符号数 | 备注 |
|---|---|---|
| `backend/agent/__init__.py` | 20 | eager import，无循环依赖 |
| `backend/adapters/__init__.py` | 7 | eager import |
| `backend/guardrails/__init__.py` | 9 | **延迟导入**（与 memory/mcp 循环依赖） |
| `backend/mcp/__init__.py` | 12 | **延迟导入**（与 guardrails 循环依赖） |
| `backend/memory/__init__.py` | 19 | **延迟导入**（与 guardrails 循环依赖） |
| `backend/mock/__init__.py` | 3 | eager import |
| `backend/skills/__init__.py` | 4 | eager import |
| `backend/__init__.py` | 2 | 顶层便捷导出 repo, runtime_config |
| `eval/__init__.py` | 4 | eager import |

### 关键技术决策

- **memory ↔ guardrails ↔ mcp 存在预存循环依赖**，使用 PEP 562 `__getattr__` 延迟导入解决。
- `mcp_server.py` 导出的是 `mcp` (FastMCP 实例) 和 `main()`，不是 `serve_mcp`。
- `llm.py` 没有 `LLMProvider` 类，没有 `get_llm` 函数；实际导出为 `get_llm_status`、`get_public_llm_status` 等。
- `tools.py` 没有 `register_tool`，工具注册用的是 `@mcp_tool` 装饰器模式。
